Опис інтерактивності та покрокова інструкція

Коротко
- Гілка в робочому каталозі: `feature/tsconfig` (локально). Я не виконував пуш — ви зробите це самостійно (як просили).
- Зміни: додано інтерактивність у `src/main.ts`, додано розмітку модального вікна та контейнер для постів у `index.html`, додано скрипт збірки у `package.json`, скомпільований файл — `dist/main.js`.

Додана інтерактивність (покроково)
- Модальне вікно
  - Кнопка `#openModal` відкриває модальне вікно (додається клас `show`).
  - Кнопка `#closeModal` закриває модальне вікно (видаляється клас `show`).
  - Натискання клавіші `Escape` закриває модал, якщо він відкритий.
  - Клік поза модальним вікном (по самому елементу `#modal`) також закриває модал.

- Лістенер на прокрутку
  - `window` слухає подію `scroll` і логить позицію прокрутки у консолі. (В демонстраційних цілях).

- Завантаження та показ постів (fetch)
  - `fetch` з `https://jsonplaceholder.typicode.com/posts?_limit=6`.
  - Отримані пости відображаються у контейнері `#posts` як блоки `<div>`.
  - Для кожного поста встановлено `data-id`.
  - Клік по посту перемикає клас `highlight` (додає/видаляє підсвітку).
  - Використано `IntersectionObserver` щоб по мірі прокрутки додавати клас `visible` (анімований прояв).
  - Просте екранування HTML (функція `escapeHtml`) для уникнення ін’єкцій.

- Додатково
  - Подвійний клік по `#header` плавно скролить сторінку вгору (`scrollTo({ top:0, behavior: 'smooth' })`).

Файли, що змінені
- `index.html` — виправлено шляхи до CSS (`css/main.css`), додано кнопку `#openModal`, модал `#modal`, контейнер `#posts`, стилі для демо, та підключення `dist/main.js`.
- `src/main.ts` — весь інтерактивний код у TypeScript з примітивними типами.
- `package.json` — додано скрипт `build` = `tsc`.
- `tsconfig.json` — вже існував; `outDir` налаштований на `./dist` (компілятор згенерував `dist/main.js`).
- `dist/main.js` — згенерований (компільований) файл (компіляція виконана локально під час підготовки).

Як запустити локально (кроки)
1. Відкрити термінал у каталозі проєкту `SLP`.
2. Встановити залежності (якщо ще не встановлені):

```bash
npm install
```

3. Скомпілювати TypeScript (генерує `dist/main.js`):

```bash
npm run build
# або
npx tsc -p tsconfig.json
```

4. Відкрити сайт локально (прості варіанти):
- за допомогою Python:

```bash
python3 -m http.server 8080
# або для іншої директорії
# (запускати у корені репозиторію)
```

- або за допомогою простого http-сервера npm:

```bash
npx http-server -p 8080
```

5. Відкрити у браузері: `http://localhost:8080/`.

Поради щодо розгортання на GitHub Pages
1. Переконайтесь, що гілка `feature/tsconfig` є локально (ви працювали на ній).
2. Зробіть коміт і запуште гілку до GitHub (ви вказали, що самі будете пушити):

```bash
git add .
git commit -m "Add TypeScript interactivity, tsconfig and build" 
git push origin feature/tsconfig
```

3. Створення GitHub Pages (варіант через веб):
- У репозиторії на GitHub відкрийте Settings → Pages.
- В розділі "Source" оберіть `branch: feature/tsconfig` і вкажіть папку `/ (root)` або `/docs` залежно від вашого вибору. Якщо ви підключаєте з `root`, сторінка опублікується з кореня (це працює для статичного HTML + `dist` потрібно додати у репо).
- Збережіть; через хвилини-годину буде доступне посилання `https://<your-username>.github.io/<repo>/` або, якщо у вас repo owner pages, то `https://<org-or-user>.github.io/`.

4. Якщо хочете, щоб `dist` файли були у корені GitHub Pages, переконайтесь, що `dist/main.js` і `index.html` знаходяться в тому місці, який обрано як Source (root). Інакше використайте GitHub Action або скрипт який копіює файли у папку `docs/` і пушить.

Покрокова інструкція (коротко, українською)
- Крок 1: Перевірити що ви на гілці `feature/tsconfig`:
  - `git branch` (або `git status`)
- Крок 2: Встановити залежності: `npm install`
- Крок 3: Скомпілювати TS: `npm run build` або `npx tsc -p tsconfig.json`
- Крок 4: Локально переглянути: `python3 -m http.server` або `npx http-server`
- Крок 5: Зробити коміт і пуш в `feature/tsconfig` (якщо готові):
  - `git add . && git commit -m "Add TS interactivity" && git push origin feature/tsconfig`
- Крок 6: На GitHub — Settings → Pages → обрати `feature/tsconfig` як Source → зберегти → почекати публікацію.

Примітки
- Я згідно з вашою приміткою не робив `git push` — ви виконаєте пуш самостійно.
- Якщо хочете, я можу: додати GitHub Action для автоматичного деплою на GitHub Pages при пуші у `feature/tsconfig`, або підготувати `docs/` копію; скажіть, і я додам.
